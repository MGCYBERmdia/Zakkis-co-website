# Zakkis-co-Website
small e‑commerce website project


## Objective
This project is a **simple e‑commerce website** built as part of my learning journey.  
The goal was to practice **frontend development (HTML, CSS, JavaScript)** and gradually expand into **full‑stack development (MERN stack)**.  
Through this project, I explored how to structure a web application, manage product listings, and implement cart functionality.

### Skills Learned
- Building responsive layouts with **HTML & CSS**.  
- Adding interactivity using **JavaScript**.  
- Using **Git & GitHub** for version control.  
- Understanding the basics of **frontend → full stack transition**.  
- Planning to integrate **MongoDB, Express.js, React, Node.js** for a complete MERN stack solution.  

### Project Details
- 🛒 **Type:** Small E‑Commerce Website  
- 🛍️ **Shop Name:** Zakkis (Unisex Accessories Shop)  
- 🎯 **Features:** Product listing, add‑to‑cart, checkout flow (basic demo).  
- 🔐 **Focus:** Secure coding practices + clean UI design.  

### Tools Used
- **Frontend:** HTML, CSS, JavaScript  
- **Version Control:** Git, GitHub  
- **Planned Full Stack:** MongoDB, Express.js, React, Node.js
